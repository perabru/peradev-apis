# Modelo de README da API do dia

Usar a identidade anos 70: amarelo #FFD447, azul #247BFF, roxo neon #A847FF e fundo #160E2B. Texto legível em temas claro e escuro. O README final deve descrever o código realmente entregue e substituir o estado planejado apenas depois dos testes.

## Estrutura

1. Banner ou capa original acessível e nome objetivo da API.
2. Benefício e caso de uso em duas ou três frases.
3. Estado da entrega e resultados reais da verificação.
4. Requisitos, instalação e comando para executar.
5. Tabela de endpoints e exemplos de entrada/saída.
6. Validação, erros, paginação, persistência e limites aplicáveis.
7. Testes: comandos e resultados efetivamente obtidos.
8. Referências oficiais: o que inspirou a implementação e como ela difere do provedor.
9. Exemplo ou demonstração fiel.
10. Colaboração por Pix.
11. Como contribuir, licença e resumo curto em inglês.
