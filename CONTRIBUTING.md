# Como contribuir

Sugestões e melhorias são bem-vindas.

- Abra uma issue descrevendo a API que gostaria de ver e o problema que ela resolve.
- Ao relatar uma falha, informe a API, a versão do Node.js, os passos para reproduzir e o resultado esperado. Remova tokens e dados pessoais dos exemplos.
- Para contribuir com código, faça um fork, crie uma branch e envie um pull request com uma descrição clara do comportamento alterado.
- Execute os testes da API afetada e documente mudanças em rotas, entradas, respostas ou persistência.

APIs Node.js da série podem ser verificadas com `npm test` na raiz. Cada projeto deve manter instruções próprias para execução.

Use somente material que você tenha direito de compartilhar, preserve a licença MIT e mantenha uma comunicação respeitosa.
