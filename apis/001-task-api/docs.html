PERADEV / API 001

Tarefas organizadas.
Uma chamada por vez.

API REST em Node.js com persistência em arquivo, validação, busca e paginação. Nenhuma dependência externa.

Baixar contrato OpenAPI

Crie sua primeira tarefa

curl http://127.0.0.1:3000/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Estudar APIs","priority":"high"}'

A resposta 201 Created inclui o UUID, os dados e as datas da tarefa. Use o UUID nas próximas chamadas.

Rotas

MétodoRotaFunção
POST/tasksCriar
GET/tasksListar e filtrar
GET/tasks/{id}Consultar
PATCH/tasks/{id}Atualizar
DELETE/tasks/{id}Excluir
GET/healthEstado

Filtre o que importa

GET /tasks?done=false&priority=high&limit=10&offset=0

Use q para buscar no título e descrição. limit aceita 1–100; offset aceita 0–5000. A resposta contém data, total, limit e offset.

Dados válidos, erros claros

title: 1–120 caracteres. description: até 1000. priority: low, medium ou high. done: booleano. Corpos JSON: até 16 KiB. Campos desconhecidos são rejeitados.

Erros usam {"error":"mensagem"}. Veja os detalhes do contrato OpenAPI.

Escopo desta versão

Uso local, um processo e até 5000 tarefas. Os dados ficam em data/tasks.json. Para dados reais na internet, são necessárias autenticação, HTTPS e uma estratégia de banco de dados.
